# TDK Technology Atlas 2026

**TDKの技術力と世界シェアを、3Dで巡る。**
1930年に日本で発明された磁性セラミックス「フェライト」から、スマホの電池、HDDの磁気ヘッド、AIデータセンターの部品まで――
2026年10月15日時点の公開情報をもとに、TDKの90年と現在を全18章・約70シーンの3Dで紹介する学習用サイトです。

> 本サイトは個人が公開情報をもとに作成した **非公式の学習用コンテンツ** で、TDK株式会社とは関係ありません。
> 世界シェアは、特に断りがない限りTDK自身の推定値（IR資料記載）です。製品の3Dモデルはイメージです。

## 見かた

- **スマホ**：横向きにして、右上の全画面ボタン（⛶）を押すのがおすすめ。iPhoneは Safari の共有メニューから「ホーム画面に追加」して開くと全画面で表示されます。
- **PC**：最新の Chrome / Edge / Safari / Firefox。

| 操作 | スマホ | PC |
|---|---|---|
| 次へ・前へ | 画面下の NEXT／PREV 矢印のみ | 画面下の NEXT／PREV 矢印のみ |
| 立体を360度まわす | ドラッグ | ドラッグ |
| 1〜15倍ズーム | ピンチ／画面の＋− | ホイール／画面の＋− |
| 詳しい解説 | 「詳しく見る」 | `I` キー |
| 目次 | ☰ ボタン | `M` キー |
| 全画面 | ⛶ ボタン | `F` キー |
| 共有 | 目次の「共有」（いま見ている章・ステップへのリンク） | 同じ（リンクをコピー） |

誤操作防止のため、画面タップ、スワイプ、スクロール、キーボード、自動再生ではフェーズが移動しません。次のフェーズへは必ず画面下の **NEXT** 矢印で進みます。視点を初期状態に戻すには、画面のリセットボタン（PCは `0` キー）を使います。

右上の目次から画質（自動／高／標準／軽量）も選べます。動作が重いときは「軽量」にしてください。

## 公開（GitHub Pages）

公開URL：**https://sc8z35a-collab.github.io/TDK-Technological-strength-2026-10-15-12-35/**

`docs/index.html` は three.js を含む単一のHTMLファイルです。`main` に変更が入るたびに GitHub Actions（`.github/workflows/pages.yml`）が公開を更新します。リポジトリの **Settings → Pages** の Source は「GitHub Actions」がおすすめです（`docs/` がそのままサイトのトップになります）。「Deploy from a branch」のままでも、このワークフローがサイトの再ビルドを依頼し、直下の `index.html` が `docs/` へ移動します。ファイルを直接ブラウザで開いても動きます。

## 開発

```bash
npm install
npm run build          # src/ → docs/index.html
npm test               # 矢印限定遷移・360度回転・15倍ズーム・演出の操作テスト
node scripts/screenshot.mjs 6.1@4   # 第6章ステップ1を撮影（ヘッドレスChromium）
```

構成や章の作り方は [`DEVELOPMENT.md`](DEVELOPMENT.md) を参照してください。

- 3D：[three.js](https://threejs.org/) r186（WebGL2）。部品・素材・光・テクスチャはすべてプログラムで生成し、写真やロゴは使っていません。
- 地図：[Natural Earth](https://www.naturalearthdata.com/)（パブリックドメイン）を `world-atlas` 経由で利用。
- フォント：Shippori Mincho B1、IBM Plex Sans JP、IBM Plex Mono（Google Fonts）。
